# 崩溃大陆七项修改器 1.3.1

修复修改器重新打开后，游戏路径总是恢复为开发者本机路径的问题。每位用户选择自己的 `Crashlands.exe` 后，后续启动会恢复该用户上次保存的路径。

## 更新内容

- 通过“浏览”选择游戏后立即保存路径；手动修改后离开路径框、启动游戏或关闭修改器时也会保存。
- 配置保存在当前 Windows 账户的 `%LOCALAPPDATA%\CrashlandsTrainer\game-path.txt`，各账户独立保存，移动或升级修改器目录后仍能读取。
- 命令行模式使用相同的路径设置；游戏文件临时不可用时保留已保存路径。
- 写入配置失败时提示用户并保留原配置；发布压缩包不包含个人路径配置。

## 使用与兼容性

适配 Windows x64、Steam build **20483884**，游戏版本为 **1.5.143-rc.0 / Publish 100.0.165.0**。

下载并完整解压 **CrashlandsTrainer-1.3.1.zip**，退出游戏和旧修改器后运行新版。EXE 和 DLL 需放在同一目录。首次使用时点击“浏览”选择自己的 `Crashlands.exe`，下次打开将自动恢复该路径。GitHub 自动生成的 Source code 压缩包不包含编译成品。

七项游戏功能沿用 1.3.0，本次仅修改启动器路径保存、构建打包和文档。
